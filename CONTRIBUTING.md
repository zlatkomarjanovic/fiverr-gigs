# Contributing

Thanks for helping improve the Fiverr gig hub.

## Prerequisites

- Node.js 20+
- No npm dependencies — scripts use the Node standard library only

## Workflow

1. Edit [`data/gigs.json`](data/gigs.json) and/or hand-maintained [`styles.css`](styles.css).
2. Set the public origin:

   ```powershell
   $env:SITE_ORIGIN="https://zlatkomarjanovic.github.io/fiverr-gigs"
   ```

3. Run the full gate before committing:

   ```bash
   npm run check
   ```

4. Commit **both** source changes and regenerated output (`index.html`, `services/*.html`, `sitemap.xml`, `rss.xml`, `robots.txt`, `llms.txt`).

## Do not edit

These files are generated by `scripts/generate-hub.mjs`:

- `index.html`, `services/*.html`, `404.html`
- `sitemap.xml`, `rss.xml`, `robots.txt`, `llms.txt`
- `{indexnow-key}.txt` at the repo root

## Adding a gig

See the **Add a gig** section in [`README.md`](README.md).

## Tests

```bash
npm test
```

Unit tests live under `scripts/lib/*.test.mjs`.

## Pull requests

CI runs `npm run check` and fails if generated files are out of date. Keep commits focused and use conventional commit messages (`feat:`, `fix:`, `docs:`, etc.).
